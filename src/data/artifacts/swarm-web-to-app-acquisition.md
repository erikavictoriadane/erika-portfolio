### Overview
Foursquare’s consumer ecosystem commanded millions of monthly mobile web visits from users searching for local business recommendations and venue reviews. However, converting these anonymous web visitors into high-LTV native app users for Swarm (Foursquare's lifelogging and social check-in app) had historically relied on expensive paid user acquisition channels.

Partnering with the Growth Product Manager, I designed and executed a multi-phase growth initiative using Branch Journeys smart banner prompts on Foursquare’s mobile web domain. Through rigorous multivariate experimentation, we tested different value propositions, modal formats, and audience segments. The initiative uncovered the most cost-effective acquisition engine in the app's history—projecting a blended Cost Per Install (CPI) of $1.07 and a 48% annual lift in organic app installs, alongside healthy multi-day user retention cohorts.

**My Role:** Experiment Design · Funnel Optimization · Copy & Creative Testing · Growth Forecasting · Cohort Retention Analysis

### The Challenge
Paid mobile app acquisition costs across Facebook and Google were climbing, making efficient growth difficult. Meanwhile, Foursquare was sitting on massive organic mobile web traffic that was left under-monetized:

- **Context Disconnect:** Mobile web visitors arrived via search engines seeking immediate venue answers; intrusive app interstitials caused immediate bounce.
- **Value Proposition Ambiguity:** Users weren't sure whether Swarm was a travel tracker, a friend finder, or a personal check-in diary.
- **Format Sensitivity:** Testing was needed to determine whether discrete floating pills, half-sheet overlays, or full-screen takeovers provided the optimal balance of conversion vs. user experience.

### The Strategy & Creative Approach
We structured a rigorous 30-day multivariate testing framework across two critical mobile web touchpoints:

> **Organic Search Query → Mobile Web Landing Page → Contextual Branch Modal → Deep-Linked App Install**

#### Experiment 1: Homepage Value Proposition Test

- **Control (10%):** No upsell banner.
- **Variant A (45%):** "Check-in" Value Prop (*"Keep track of the places you visit"*).
- **Variant B (45%):** "Travel" Value Prop (*"Your personal travel log"*).
- **Winner:** Variant A ("Check-in") drove superior conversion, proving users responded best to immediate utility.

#### Experiment 2: Venue Page UX Format Test

- **Control (10%):** No upsell.
- **Variant A (30%):** Full-Page Modal.
- **Variant B (30%):** Floating Pill Banner.
- **Variant C (30%):** Half-Page Slide-Up.
- **Winner:** Full-Page Modal with clear contextual framing delivered the highest install conversion rate.

### Key Takeaway / Learning
Conversion optimization doesn't end when the app is installed. By measuring down-funnel retention cohorts alongside acquisition unit economics, growth marketing proved that converting owned web traffic delivers both lower acquisition costs and higher customer lifetime value.
